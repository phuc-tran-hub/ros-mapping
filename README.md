I wrote a node that implemented Occupancy Grid Mapping from scratch, without using any pre-built mapping packages. The node used laser data collected by the robot as it moved to create a dynamic occupancy grid, reflecting the odom reference frame. The grid differentiated between unknown areas, free space, and obstacles. I published the map using the nav_msgs/OccupancyGrid message format, ensuring it was compatible with ROS visualization tools for real-time monitoring and analysis.
